## Установка

Удобная установка доступна из [релизов](https://github.com/KirillkoTankisto/iiko-office/releases/latest) для **Arch**/**Debian** подобных дистрибутивов и **macOS**. Скачайте нужный пакет и проделайте следующие действия:

Arch:
```sh
pacman -U имя_пакета.tar.zst
```
Debian:
```sh
dpkg -i имя_пакета.deb
```

macOS: <br> Откройте образ, проследуйте инструкциям и перетащите программу в папку _Applications_
